# Cek Kehadiran Onboarding

Aplikasi web sederhana untuk memantau dan mengecek kehadiran peserta onboarding berdasarkan tanggal dan lokasi warehouse.

## Fitur
- Filter berdasarkan Tanggal Onboarding.
- Pilihan Lokasi Onboarding (Online Onboarding, WH Bitung, WH Bogor, WH Cibinong, WH Cibitung, WH Pegangsaan, WH Sentul, WH Srengseng).
- Integrasi dengan Google Apps Script dan Google Sheets.
